This work presents a protocol for deciding whether a candidate behavioral partition is empirically stable enough to become the target of mechanistic investigation. Rather than assuming a behavioral category (e.g., 'refusal') is a coherent object, this pre-registered adjudication experiment applies controlled structural and isomorphic perturbations to test its stability. If the regime dissolves under perturbation, it is an artifact of prompt phrasing, not a mechanism. If it holds, it provides a rigorously defined, experimentally individuated object against which explanatory frameworks (circuits, dynamical systems, control theory) can be fairly compared."


"This work presents a protocol for deciding whether a candidate behavioral partition is empirically stable enough to become the target of mechanistic investigation. Rather than assuming a behavioral category (e.g., 'refusal') is a coherent, localized mechanism, this pre-registered experiment tests its stability. We apply controlled structural and isomorphic perturbations to a language model to observe its output trajectory. If the behavioral regime dissolves under perturbation, it is an artifact of prompt phrasing, not a stable mechanism. If it holds, it provides a rigorously defined, experimentally individuated object against which explanatory frameworks (such as circuits or dynamical systems) can be fairly compared."
