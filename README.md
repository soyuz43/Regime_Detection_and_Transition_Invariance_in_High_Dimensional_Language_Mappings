# Regime Detection and Transition Invariance in High-Dimensional Language Mappings

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

## Overview

This work presents a protocol for deciding whether a candidate behavioral partition is empirically stable enough to become the target of mechanistic investigation. Rather than assuming a behavioral category (e.g., 'refusal' or 'withholding') is a coherent, localized mechanism, this pre-registered experiment tests its stability through controlled perturbation.

We apply structural and isomorphic perturbations to a language model to observe its output trajectory. If the behavioral regime dissolves under perturbation, it is an artifact of prompt phrasing rather than a stable mechanism. If it holds, it provides a rigorously defined, experimentally individuated object against which explanatory frameworks—such as circuits, dynamical systems, or control theory—can be fairly compared.

## Key Contributions

-   **Behavioral Adjudication:** A pre-registered framework to validate if a behavioral label represents a true computational regime or a superficial prompt artifact.
-   **Perturbation Testing:** Methodology for distinguishing between surface-level sensitivity (isomorphic changes) and deep structural sensitivity (semantic/intent changes).
-   **Null Model Baselines:** Rigorous comparison against lexical, length-based, and constant predictors to prove genuine contextual integration.
-   **Transition Probability Mapping:** Quantifying the stochastic boundaries of behavioral regimes rather than treating them as binary deterministic states.
